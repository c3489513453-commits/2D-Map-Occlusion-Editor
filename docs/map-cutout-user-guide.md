# 地图抠图工具使用说明

## 启动

双击项目根目录的 `启动工具.bat`。终端窗口需要保持打开，浏览器会自动显示工具；关闭终端窗口即停止工具。所有图片和项目文件都只在本机处理。

工具会记住最近一次成功打开或保存的项目，下次启动时自动恢复。尚未按 `Ctrl+S` 保存的项目状态不会自动写入项目文件。

## 建立项目和导入地图

点击“新建项目”选择保存文件夹；点击“导入图片”加入一张地图，或“导入文件夹”一次加入其中的 PNG、JPG、JPEG。左侧切换地图，右侧始终保留“原始地图”底图。

## 自动识别

输入英文物体短语并用句点分隔，例如 `chair. wooden door. stone wall.`。短语应简短、具体；长段落通常不会更准确。阈值默认 0.40，漏检时逐步降低，误检多时提高。所有结果分别建立为 `chair1`、`chair2` 等图层，一次识别可用一次撤销取消。

## 手动分割和修正

- “框选”：拖出目标范围，点击“生成蒙版”，预览正确后“建立图层”。
- “正点”点击目标内部，“负点”点击不应包含的区域，生成预览后确认。
- “画笔”和“橡皮”：先在对应图层点击“编辑”，再涂抹补充或删除；一次连续笔画对应一次撤销。
- 鼠标滚轮缩放；按住空格拖动画布。

## 图层、保存和撤销

眼睛在名称左侧，控制整个图层的显示和隐藏。图层最右边的小圆点控制橙色遮挡辅助信息的显示和隐藏，不会删除遮挡关系。按 Ctrl 或 Shift 多选，点击“合并选中”会建立新合并层并隐藏源层。使用“＋ 文件夹”进行整理。按 `Ctrl+S` 保存，`Ctrl+Z` 撤销，`Ctrl+Y` 或 `Ctrl+Shift+Z` 重做。工具不会自动保存。

## 绘制和预览人物遮挡

1. 点击顶部“导入小人”，选择带透明背景的 PNG。工具自动把最下面一行非透明像素识别为人物脚底接触段。
2. 点击顶部“自动底线”，会为当前地图中还没有底线的蒙版批量生成橙色底线。已经修正过的底线不会被覆盖。
3. 在右侧目标图层点击“编辑底线”，按钮会变为“退出编辑”。拖动已有底线的圆形节点可调整位置；点击线段会选中整条底线，按 `Delete` 或退格键删除。
4. 如需新增底线，在编辑状态下点击画布下方的“画底线”，左键逐个增加节点，右键完成并保存。按 `Esc` 取消尚未完成的一笔。
5. 小人脚底接触段只要有一点进入底线上方，该蒙版物体就会盖住小人；整段离开遮挡侧后，小人会显示在物体前面。
6. 使用“↖ 选择与移动”拖动小人。点击顶部“预览”会隐藏蓝色蒙版、橙色底线和编辑标记，只显示完整地图、小人以及最终遮挡效果。按 `Ctrl+S` 才会把底线写入 `project.json`。

## 绘制可行走区域

右侧默认显示“资源蒙版”。点击标题处的“行走区域”切换到独立的行走图层列表。使用“＋图层”和“＋文件夹”建立、整理多条道路，再在目标图层点击“编辑”。绿色部分表示人物可以站立和行走的地方，可用画笔、框选或“套索增加”补充，用橡皮或“套索减去”删除。行走图层之间以及行走区域与资源蒙版之间都可以重叠。

导入小人后，人物脚底接触段必须全部位于所有可见绿色图层的并集内才能移动；越界时人物会留在上一个有效位置。预览模式会隐藏绿色提示，但仍会执行行走限制。切回“资源蒙版”即可继续编辑物品蒙版和底线。导入的小人及大小会保存到当前项目，强制刷新或重新打开项目后自动恢复。

## 导出透明 PNG

点击“导出”选择范围和尺寸。“紧凑裁剪”只保留素材占用区域；“保持原图尺寸”输出与地图相同尺寸，其他位置透明。可导出选中、可见、全部或整个项目，也可保留文件夹结构。输出目录留空时使用项目的 `exports` 文件夹。

勾选“导出遮挡与行走配置 JSON”会只建立一套可测试的地图逻辑包，不会再在外层重复导出普通透明素材。包内的 `map.png` 是完整地图，`occluders` 文件夹中的 PNG 是原图尺寸遮挡层，`walkable.png` 保存同尺寸行走区域；`occlusion.json` 的 `walkable` 字段记录行走图、参与合并的图层及“角色脚底必须位于行走区域内”的规则，并用 `occluders[].lines` 保存各遮挡层底线。兼容字段 `walkableMask` 仍然保留。后续程序只需整套复制这个文件夹。
