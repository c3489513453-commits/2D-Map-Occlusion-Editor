# 本地地图素材抠图工具设计

## 目标

在现有 Grounded SAM 2 项目上构建一个中文本地浏览器工具，用于从一张或一批 2D 游戏地图中识别物体、修正蒙版、按图层管理结果，并导出透明 PNG。所有模型、图片、项目文件和输出均保留在本机。

第一版面向非技术用户。用户通过双击启动文件打开工具，不需要输入 PowerShell 命令。

## 第一版范围

第一版包含：

- 导入单张地图或整个地图文件夹。
- 通过英文短提示词和检测阈值调用 Grounding DINO 与 SAM2。
- 将全部检测结果直接建立为独立图层。
- 使用框选、正点、负点、画笔和橡皮擦创建或修正蒙版。
- 通过图层和手动文件夹管理素材。
- 保存和重新打开项目。
- 将一个、多个或全部图层导出为透明 PNG。
- 导出紧凑裁剪尺寸或原图尺寸。

第一版不包含模型训练、游戏遮挡最低线、碰撞数据、传送逻辑、Photoshop 自动化、云端同步、多人协作和视频处理。

## 运行与隐私

工具由一个双击启动文件启动本地 Python 服务，并自动打开默认浏览器。本地服务只监听回环地址，不向局域网或互联网公开。除模型首次下载外，地图处理不需要网络，图片不上传到外部服务。

关闭启动窗口时停止本地服务。浏览器关闭但服务仍在运行时，用户可以重新打开本地地址继续使用尚未退出的会话。

## 页面布局

界面采用三栏专业编辑器布局：

```text
┌────────────────────────────────────────────────────────────────────────┐
│ 打开文件夹 │ 打开图片 │ 保存 Ctrl+S │ 撤销 Ctrl+Z │ 重做 │ 导出 ▼   │
├──────────────┬───────────────────────────────────┬─────────────────────┤
│ 地图列表     │ 地图、检测框与蒙版编辑画布        │ 图层管理            │
│              │                                   │ 👁 chair1      🔒   │
│ 布莱庄园     │ 缩放、平移                        │ 👁 chair2      🔒   │
│ 地下祭坛     │ 选中、点击、框选                  │ ◯ door1        🔒   │
│ 地下通道     │ 正点、负点、画笔、橡皮擦          │ ▼ 家具文件夹        │
│ ……           │ 半透明蒙版预览                    │   👁 table1    🔒   │
│              │                                   │ 👁 原始地图   🔒   │
├──────────────┴───────────────────────────────────┴─────────────────────┤
│ 提示词 │ 检测阈值 │ 开始识别 │ 选择 │ 框选 │ 正点 │ 负点 │ 画笔   │
└────────────────────────────────────────────────────────────────────────┘
```

图层左侧放显示/隐藏按钮，锁定按钮放在图层右侧。中间画布支持缩放和平移，并以可调透明度显示彩色蒙版。

## 地图与项目管理

用户可以打开单张图片或整个文件夹。支持的第一版输入格式为 PNG、JPG 和 JPEG。文件夹中的受支持图片出现在左侧地图列表中，并按文件名排序。

每张地图拥有独立的图层树、蒙版、提示词和阈值。默认项目目录为：

```text
D:\06\剧本\地图抠图\项目输出
```

用户可以通过“另存项目”选择其他位置。工具不自动保存；`Ctrl+S` 和顶部“保存”按钮执行保存。切换地图、关闭页面或退出服务前如有未保存修改，界面应明确警告。

项目保存采用先写临时文件、验证完成后替换正式文件的方式。项目记录：

- 原始地图路径及重新定位信息。
- 地图列表和当前地图。
- 提示词与检测阈值。
- 每个图层的蒙版、名称、顺序、显隐和锁定状态。
- 图层文件夹结构。
- 当前选择和导出设置。

原始图片丢失时，重新打开项目会要求用户定位文件，不会删除已有蒙版和图层数据。

## 原始地图图层

每张地图导入后自动建立“原始地图”图层，并固定在图层树最底部。该图层默认显示和锁定，但允许隐藏和手动解锁。

任何编辑都只影响项目中的派生状态，不覆盖源文件。导出整套素材时包含原始地图；默认按源格式复制，且保持原始尺寸。

## 自动识别

提示词使用适合 Grounding DINO 的英文短名词或名词短语，并以英文句号分隔，例如：

```text
chair. table. stone wall. gate. wooden door.
```

界面提供检测阈值滑块，默认值为 `0.4`。用户可以降低阈值寻找遗漏对象。

开始识别后，所有结果直接成为独立图层，不经过候选确认。图层按类别连续命名，如 `chair1`、`chair2` 和 `door1`。再次识别时继续现有编号，不覆盖已有图层。高度重合的检测结果可以提示用户，但工具不自动删除。

没有识别结果时，保留所有现有图层并显示中文提示。

## 手动创建与蒙版修正

工具支持以下画布模式：

- 选择：选择检测框、蒙版或图层。
- 框选：框出目标的大致范围，调用 SAM2 生成蒙版。
- 正点：标记应属于目标的区域。
- 负点：标记不应属于目标的区域。
- 画笔：直接增加蒙版区域。
- 橡皮擦：直接删除蒙版区域。
- 平移：移动大图视口。

用户可以组合一个框和多个正负点，预览后确认蒙版。手动确认的新对象自动建立为独立图层。画笔和橡皮擦提供尺寸调节。所有蒙版编辑都在原始图像坐标系中保存，缩放和平移不会改变蒙版分辨率。

## 图层与文件夹

普通图层支持显示、隐藏、锁定、解锁、重命名、删除、复制、多选、排序、合并和拖入/移出文件夹。

文件夹只能由用户手动新建，不按照识别类别自动生成。文件夹支持重命名、折叠、展开、整体显示、整体隐藏、接收拖入图层，以及删除空文件夹。删除非空文件夹时必须让用户选择“仅删除文件夹并移出图层”或“同时删除其中图层”。

合并选中图层会建立一个使用蒙版并集的新图层；原图层默认保留并自动隐藏，用户可以随后删除。这样合并操作不会立刻破坏源图层。

隐藏只影响画布和“导出可见图层”，不会删除蒙版，也不阻止显式的单图层导出。

## 撤销与重做

快捷键如下：

- `Ctrl+S`：保存项目。
- `Ctrl+Z`：撤销。
- `Ctrl+Y` 或 `Ctrl+Shift+Z`：重做。

撤销范围包括蒙版绘制、图层创建与删除、合并、重命名、移动、显隐和锁定状态。每张地图独立保留最近 50 步。保存项目不清空当前会话的撤销记录，但重新启动后不恢复历史撤销栈。

## 导出

导出入口支持：

- 当前单个图层。
- 当前多选图层，分别输出文件。
- 当前文件夹中的全部图层。
- 当前地图全部可见图层。
- 当前地图所有图层，包括隐藏图层。
- 项目中所有地图的全部图层。

每次导出可选择：

1. 紧凑裁剪：按蒙版非透明边界裁剪，只保留物体实际范围。
2. 原图尺寸：输出尺寸与原地图一致，物体保持原坐标，其他区域透明。

识别图层统一导出 RGBA PNG。完全空白的蒙版不导出，并说明具体图层。输出文件名移除 Windows 非法字符；重名时自动添加连续编号。图层文件夹可选择是否映射为实际输出子目录。

默认导出到项目目录下的 `exports`，用户可为每次导出选择其他位置。

## 模块边界

实现拆分为以下模块：

- `inference`：加载 Grounding DINO 与 SAM2，处理文字、框和点提示。
- `project`：项目结构、地图引用、图层树和持久化。
- `masks`：蒙版组合、画笔编辑、边界计算和重复检测。
- `export`：两种尺寸策略、批量导出和命名冲突处理。
- `history`：每张地图独立的撤销/重做命令栈。
- `web`：本地服务、中文页面、画布交互和快捷键。
- `launcher`：启动检查、服务启动和自动打开浏览器。

模型模块只返回检测框、类别、置信度和原图尺寸蒙版，不直接修改项目。项目模块不依赖具体模型，以便以后替换或微调识别模型。

## 数据流

```text
导入图片/文件夹
    → 建立地图记录与原始地图图层
    → 文字识别或手动框/点提示
    → SAM2 输出原图尺寸蒙版
    → 建立独立图层
    → 用户修正与组织图层
    → 保存项目
    → 按选定范围和尺寸导出透明 PNG
```

耗时推理和导出任务在后台执行，并向页面报告阶段与进度。任务运行期间禁止对相关地图执行冲突操作，但允许查看其他地图。

## 错误处理

- CUDA 显存不足：显示中文错误，释放临时显存，并提供降低处理分辨率后重试的选项。
- 模型或权重缺失：显示缺失文件和修复建议，不显示原始 Python 堆栈作为主提示。
- 项目或导出目录不可写：要求重新选择位置。
- 图片读取失败：标记具体文件并继续加载文件夹中的其他图片。
- 推理取消或失败：不建立半成品图层，不修改已有图层。
- 保存失败：保留原项目文件和临时恢复文件。

## 测试与验收

单元测试覆盖：

- 图层连续命名和重名处理。
- 文件夹移动、删除和显隐规则。
- 蒙版并集、画笔增减和空蒙版检测。
- 紧凑裁剪与原图尺寸导出。
- 中文路径、非法文件名和输出冲突。
- 项目保存、重新加载和源图重新定位。
- 撤销/重做的 50 步上限和地图隔离。

集成测试覆盖：

- 用已缓存模型完成文字识别并建立图层。
- 用框和正负点生成蒙版。
- 保存项目、重启服务并恢复图层状态。
- 批量导出一张地图和整个项目。

人工验收使用现有地图素材，至少验证“布莱庄园”和“地下祭坛”：

- 文件夹导入和地图切换可用。
- 自动识别结果直接进入图层。
- 原始地图始终位于底层且默认锁定。
- 点击、框选和画笔能够修正蒙版。
- 图层文件夹、显隐、锁定、合并和撤销符合设计。
- 两种导出尺寸均生成有效透明 PNG。
- 关闭前能提示未保存修改。
