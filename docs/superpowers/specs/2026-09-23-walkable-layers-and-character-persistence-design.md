# 行走图层与小人持久化设计

## 目标

把当前每张地图只有一个特殊行走蒙版的实现，升级为与资源蒙版平行的独立行走图层系统，并让测试小人在刷新页面或重新打开项目后自动恢复。

## 用户界面

右侧图层面板保留“资源蒙版 / 行走区域”切换，默认显示资源蒙版。切到行走区域后，标题栏显示“＋图层”和“＋文件夹”，操作方式与资源蒙版一致：建立空白图层、命名、编辑、显示或隐藏、删除、拖动排序、拖入文件夹以及折叠文件夹。

行走图层不显示资源蒙版专属的底线编辑、遮挡信息圆点和合并选中。资源蒙版模式的现有行为不变。

编辑行走图层时，已保存区域、画笔笔迹、框选和套索预览统一使用绿色；资源蒙版仍使用蓝色。未选中行走图层时使用绘制工具，应提示先在右侧建立或编辑一个行走图层。

## 数据模型和兼容

每张地图新增 `walkable_layers` 和 `walkable_folders`，结构复用现有 `LayerState` 和 `FolderState`。行走图层的 `kind` 固定为 `walkable`，蒙版为与地图同尺寸的灰度 PNG，保存在该地图的蒙版目录下。

旧项目中的单一 `walkable_mask_path` 在读取时自动迁移为名为“行走区域”的第一个行走图层；原文件继续复用，不丢失已经绘制的区域。没有旧行走图的项目从空列表开始，不自动建立无意义图层。保存后写入新结构，同时保留兼容读取逻辑。

资源图层与行走图层允许任意重叠。资源识别、资源图层合并、自动底线和遮挡判断只处理资源图层，不处理行走图层。

## 编辑接口

为每张地图提供行走图层的列表、新建、修改、删除、绘制，以及行走文件夹的新建和删除接口。绘制沿用资源蒙版的画笔、橡皮、多边形和矩形数据格式，但使用独立路径，避免误报“请先选择一张已有蒙版”。撤销和重做覆盖行走图层建立、删除、排序、分组和绘制。

切换地图、切换项目或保存前，必须等待行走蒙版尚未完成的写入，规则与资源蒙版一致。

## 行走判断

所有可见行走图层组成可行走区域的并集。小人脚底接触段使用左端、中点和右端三个检测点；三个点都落在可见行走图层并集内才允许移动，否则人物停在上一个有效位置。

没有任何可见行走图层时，不限制测试人物移动，保证旧项目和尚未绘制道路的地图仍可预览遮挡。存在行走图层但全部为空时，没有位置可行走。

预览模式隐藏绿色辅助显示，但继续执行行走限制。

## 小人持久化

导入小人后，把 PNG 原始内容保存到当前项目的资产目录，并在项目数据中记录相对或可迁移路径。页面启动和打开项目时，通过后端接口读取已保存的小人并重新计算脚底接触段、恢复当前显示大小。

小人属于项目而不是单张地图，同一项目的所有地图共用一个测试人物。再次导入会替换项目内的测试人物。没有保存过小人的旧项目保持现状，不自动创建人物。

浏览器上传使用受尺寸限制的 PNG 数据；拒绝完全透明、无法解码或超过限制的内容，并返回中文错误。项目保存失败时不删除此前可用的小人文件。

## 导出

勾选“导出遮挡关系配置”时，把所有行走图层的蒙版取并集，输出一张与原图同尺寸的 `walkable.png`。`occlusion.json` 继续使用 `walkableMask: "walkable.png"` 引用它，遮挡图层和底线格式不变。

如果地图没有行走图层，JSON 中的 `walkableMask` 为 `null`，不生成空白图片。隐藏的行走图层是否参与导出，遵循导出对隐藏图层的现有选项。

## 测试和验收

- 旧单行走蒙版项目加载后自动得到一个行走图层，像素不变。
- 行走图层和文件夹可建立、保存、重新打开、重命名、隐藏、排序和删除。
- 在行走模式编辑不会调用资源图层接口，笔迹与蒙版提示为绿色。
- 多个可见行走图层按并集限制人物，隐藏层不参与；没有行走层时不限制移动。
- 导入小人后强刷页面、重启服务和重新打开项目仍能恢复小人及显示大小。
- 导出合并后的 `walkable.png` 尺寸和像素正确，JSON 引用正确。
- 现有资源蒙版、底线、遮挡预览和旧项目测试全部继续通过。
