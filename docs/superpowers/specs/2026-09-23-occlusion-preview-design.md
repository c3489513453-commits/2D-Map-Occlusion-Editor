# 地图遮挡区域与人物预览设计

## 目标

在现有地图蒙版编辑器中增加“固定地图场景遮挡单个测试人物”的制作与预览闭环。用户为某个蒙版图层绘制一个或多个触发区域；测试人物的脚底进入区域时，该图层的原始图像像素绘制在人物上方。

第一版不实现人物之间的 Y 坐标排序、房屋/门洞/桥梁的特殊规则、深度图、人物脚底点手动校正或游戏引擎集成。

## 核心概念

- **物体蒙版**：现有灰度 PNG，定义哪些原地图像素能够遮住人物。编辑状态继续使用蓝色高亮。
- **遮挡区域**：与某个蒙版图层绑定的一个或多个地图坐标多边形。人物脚底进入任意多边形时启用该图层的遮挡。
- **测试人物**：用户导入的透明 PNG，只用于浏览器内预览，不加入地图图层。
- **脚底点**：人物 Alpha 通道最低非透明行中，非透明像素范围的水平中心。人物位置变化时转换为地图坐标。

遮挡区域是独立空间数据，可以位于物体蒙版内部或外部；它不会被画入蒙版 PNG。

## 数据模型与保存

每个蒙版图层增加可选的遮挡区域数组：

```json
{
  "id": "tree_01",
  "name": "大树1",
  "kind": "mask",
  "mask_path": "...",
  "occlusion_regions": [
    [[410, 320], [490, 320], [510, 430], [390, 430]]
  ]
}
```

坐标原点为地图左上角，单位为原图像素。旧项目缺少该字段时按空数组读取，保证向后兼容。区域修改后标记项目为未保存；继续遵循用户按 `Ctrl+S` 写入 `project.json` 的现有规则。

人物图片和当前位置不进入地图导出数据。第一版人物预览状态只保留在当前浏览器会话中。

## 图层行交互

蒙版图层行调整为：

```text
[整层显隐] 图层名称 [编辑] [绘制遮挡] [遮挡信息显隐]
```

- 删除“蒙版”文字。
- “继续编辑”缩短为“编辑”。
- “绘制遮挡”在每个蒙版图层行中显示。点击后选中该图层并进入遮挡区域绘制模式。
- 原锁定按钮改为该图层遮挡辅助信息的显示/隐藏按钮，沿用最右侧现有的小圆形图标和紧凑尺寸，不增加文字标签。隐藏只影响橙色区域、边线和节点，不删除数据、不停止实际遮挡。
- 最左侧现有显隐按钮继续控制整个蒙版图层；隐藏的图层不参与预览遮挡。
- 删除遮挡数据采用独立操作，不能与辅助信息显隐混用。

## 遮挡区域绘制

进入绘制模式后，中央画布显示当前图层的蓝色蒙版，并使用区别明显的样式绘制空间信息：橙色半透明填充、橙色实线边界、黄色节点。

- 单击依次添加节点。
- 点击起点闭合；至少三个不同节点才可保存。
- `Esc` 取消当前尚未闭合的区域。
- 同一图层允许保存多个互不相连的区域。
- 保存、删除和修改区域均通过后端接口更新内存项目状态，并接入现有撤销体系；最终仍由 `Ctrl+S` 保存项目清单。
- 切换地图、打开项目或删除图层时清理不再有效的前端编辑状态。

第一版支持画出、显示、隐藏和删除完整区域。第一版不提供节点拖动修改；画错时删除该区域后重画，数据格式保留后续增加节点编辑的能力。

## 测试人物与选择工具

顶部工具行增加“导入小人”按钮，接受透明 PNG。人物加载后根据 Alpha 通道计算脚底点；完全透明的图片应提示中文错误。

下方原“选择”工具改名为“选择与移动”，使用鼠标指针/移动含义清晰的图标：

- 点击可见蒙版时仍选中右侧对应图层。
- 在人物上按下并拖动时移动人物，不移动地图图层。
- 人物位置限制在地图画布可操作范围内。
- 人物可调整显示比例，以适应不同地图与素材尺寸。

## 纯净预览模式

顶部增加“预览”按钮。进入后按钮改成“退出预览”，并：

- 隐藏蓝色蒙版高亮、橙色区域、边界、节点、脚底标记和图层选中高亮。
- 禁用蒙版与遮挡区域编辑操作。
- 只显示完整原地图和测试人物。
- 保留人物拖动能力。
- 每次移动按人物脚底地图坐标检测所有可见图层的遮挡区域。
- 对每个命中图层，从原地图按该层蒙版提取 RGBA 像素并绘制到人物上方；未命中图层不额外叠加。
- 多个区域或多个图层同时命中时，所有对应遮挡层均参与绘制，并沿用右侧图层顺序。

退出预览后恢复进入前的图层选择、工具和辅助信息显隐状态，并保留人物当前位置。

若尚未导入人物，点击预览时阻止进入并显示“请先导入测试人物”的中文提示。

## 遮挡包导出

导出界面增加“导出遮挡关系配置”选项。勾选后：

- 仅导出具有有效遮挡区域且当前可导出的蒙版图层。
- 遮挡 PNG 强制采用与原地图相同尺寸，保持左上角 `(0, 0)` 对齐。
- 输出 `occlusion.json`，记录版本、地图尺寸、左上角坐标系、图层 ID、名称、PNG 相对路径与全部多边形区域。
- 文件名继续使用现有 Windows 安全命名及重名处理逻辑；JSON 必须引用最终实际文件名。
- 无遮挡区域的普通蒙版不写入 `occlusion.json`，但不影响现有普通导出功能。

示例目录：

```text
导出目录/
├─ occlusion.json
└─ occluders/
   ├─ 大树1.png
   └─ 墙1.png
```

## 接口边界

后端负责区域数据校验、项目状态更新、撤销命令与遮挡包导出。前端负责画布坐标转换、人物 Alpha 脚底计算、区域绘制交互、点包含判断和实时合成预览。

区域接口必须拒绝少于三个点、非有限数值、越出合理地图坐标范围或不存在图层的数据，并返回中文错误。普通旧项目和没有遮挡数据的图层必须继续正常加载。

## 验证标准

- 旧 `project.json` 可以正常打开、保存，并为旧图层补空区域默认值。
- 区域数据保存后重启工具仍存在。
- 每行按钮文字与布局符合设计，原蒙版编辑功能不回退。
- 导入带透明空白的人物时，脚底取最低非透明像素而非 PNG 底边。
- 人物进入/离开区域时，对应原色地图像素正确盖住/放开人物。
- 预览模式不显示任何蓝色或橙色编辑辅助信息，退出后状态恢复。
- 隐藏图层不参与遮挡；仅隐藏遮挡辅助信息不影响遮挡结果。
- 遮挡包中的 PNG 均与原地图同尺寸，JSON 中的路径和区域坐标可对应到文件。
- 现有 Python 测试和浏览器画布/图层测试继续通过，并新增数据兼容、接口、导出、脚底计算、区域命中与预览状态测试。
