## 1. 项目在做什么

这是一个基于 Grounded SAM 2 的 Windows 本地 2D 地图素材分离工具，面向非技术用户。

用户导入一张或一批地图后，可以：

- 用英文提示词识别椅子、门、建筑、墙等对象。
- 用框选、正点、负点辅助 SAM 2 分割。
- 把每个识别结果保存为独立蒙版图层。
- 用画笔、橡皮、套索增加、套索减去继续修整已有图层。
- 显示、隐藏、锁定、删除、重命名、排序、合并图层，并用文件夹整理图层。
- 导出紧凑裁剪的透明 PNG，或与原图尺寸相同的透明 PNG。

当前阶段只负责识别、蒙版编辑和透明素材输出，不实现游戏内人物遮挡逻辑。

## 4. 当前未提交修改的准确内容

### 4.1 切换操作必须等待蒙版写完

文件：

```text
map_cutout/static/app.js
map_cutout/static/inference_controls.js
tests/web/canvas_editor.test.html
```

`InferenceControls.flushPendingEdits()` 等待 `paintChain` 完成。下列操作执行前都会先等待画笔或套索写入服务器：

- 切换地图。
- 删除当前地图。
- 保存项目。
- 新建项目。
- 打开项目。
- 导入单张图片。
- 导入文件夹。

目的：避免用户刚画完套索就切换地图或保存，导致请求仍在队列中，回来后看起来少了一块。

### 4.2 编辑已有图层时，框选识别直接并入当前蒙版

文件：

```text
map_cutout/web_app.py
tests/map_cutout/test_api.py
```

没有编辑图层时，框选仍然生成预览，再建立新图层。

点击“继续编辑”后，框选走：

```text
POST /api/maps/{map_id}/layers/{layer_id}/segment-add
```

SAM 识别结果直接与当前蒙版取并集，不新建图层。即使该区域和其他图层重叠，也允许叠加进当前图层。不要恢复之前的 `take_unoccupied(...)` 过滤逻辑；用户已明确要求编辑当前图层时直接合并重叠区域。

### 4.3 启动时自动恢复上次项目

文件：

```text

map_cutout/web_app.py
tests/map_cutout/test_api.py
docs/map-cutout-user-guide.md
```

记录文件：

```text

```

行为：

- 成功调用“打开项目”后记录项目目录。
- 成功按 `Ctrl+S` 保存后记录项目目录。
- 下次启动时，`create_app()` 调用 `load_startup_project()` 自动加载记录中的 `project.json`。
- 记录不存在、JSON 损坏、项目目录消失或 `project.json` 不存在时，安全回退到空白的“未命名项目”，不能让服务启动失败。
- 新建但从未保存的项目不会成为可恢复项目；用户至少要保存一次。
- 最近项目记录采用临时文件写入后原子替换，避免写到一半损坏。

## 6. 重要行为，不要回退

- 原始地图也显示为图层，但不能删除或作为蒙版编辑。
- 图层支持删除、显隐、锁定、重命名、排序、合并和文件夹管理。
- 删除图层、文件夹或地图不弹确认；可以用 `Ctrl+Z` 撤回支持撤回的图层操作。
- 删除地图只删除项目内记录、该地图的蒙版目录和缩略图，不能删除源图片。
- 可以先创建全黑的空蒙版图层，再用画笔或套索编辑。
- 套索必须保存实际勾勒区域；连续增加、减去和画笔修改要累积在同一图层。
- 自动识别创建新图层时，已有蒙版优先占用重叠像素。
- 编辑已有图层的 `segment-add` 是例外：识别结果允许和其他图层重叠，并直接并入当前层。
- 切换地图时必须清理前端蒙版本地缓存，但不能丢掉尚未完成的保存队列。
- 蒙版是灰度 PNG，黑色为透明区域，白色为保留区域；保存继续使用 `to_mask_image()`。
- 撤销与重做历史是内存状态，服务重启后不恢复历史栈。

## 9. 带到另一个分支的安全方式

切换分支前先执行：

```powershell
git status --short
git diff --check
```

当前工作区包含用户已在使用的功能，不能直接切换分支覆盖它。推荐两种方式：

1. 在用户明确同意后，把当前 8 个文件作为一个或多个本地提交，再在目标分支 `cherry-pick` 对应提交。
2. 如果暂时不提交，使用 `git diff --binary` 生成补丁，确认补丁保存在仓库外，再到目标分支应用。

不要只复制本交接文档后就认为代码已经转移。自动恢复项目、等待蒙版保存、编辑框选叠加等实现都仍在未提交工作区中。
